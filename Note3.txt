**copia file di una cartella in un'altra 
* es. xcopy C:\Users\utx004c\Desktop\cartella C:\Users\utx004c\Desktop
* es. xcopy test.txt FolderNew\text.txt
* sintassi: xcopy "<nome file/*.estesione (es. *.txt)" "destinazione"
per tutti i file .txt del folder corrente es.
* xcopy /s /y
*  /S: Copia anche i sottodirectory. 
*  /Y: Sopprime la richiesta di conferma prima di sovrascrivere un file esistente. 
*  /-Y: Richiede la conferma prima di sovrascrivere un file esistente. 
*  /I: Se la destinazione non esiste, la forza ad essere una directory. 
*  /H: Copia anche i file nascosti e di sistema. 
*  /T: Crea la struttura delle directory, ma non copia i file. 
*  /U: Copia solo i file che esistono già nella destinazione. 
*  /K: Mantiene gli attributi dei file, incluso l'attributo di sola lettura. 
*  /N: Copia utilizzando i nomi brevi generati. 

* Altro:
* *  /E: Copia anche i sottodirectory vuoti (deve essere usato insieme a /S). 
* *  /Q: Non visualizza i nomi dei file durante la copia. 
* *  /F: Visualizza i nomi completi di origine e destinazione durante la copia. 
* *  /L: Visualizza solo i file che verrebbero copiati, senza copiarli effettivamente. 
* *  /R: Sovrascrive i file di sola lettura. 
* *  /O: Copia le informazioni di proprietà e ACL dei file. 
* *  /X: Copia le impostazioni di audit dei file (implica /O). 
* *  /Z: Copia i file di rete in modalità riavviabile. 
* *  /V: Verifica la dimensione di ogni nuovo file. 
* *  /W: Richiede di premere un tasto prima di iniziare la copia. 
* *  /C: Continua la copia anche se si verificano errori. 
* *  /G: Consente la copia di file crittografati su destinazioni che non supportano la crittografia. 
* *  /D:data: Copia solo i file modificati dopo la data specificata. 
* *  /M: Copia i file contrassegnati come di archivio e rimuove il flag di archivio dalla destinazione. 
* *  /A: Copia solo i file contrassegnati come di archivio. 
* *  /B: Copia i file come file binari. 
* *  /J: Copia i file utilizzando il buffer I/O di grandi dimensioni.

E’ simile a Note++, la differenza è che nel replace usa il $
Es. replace:: $1__$2__$3
expression
	. (…) => indica il contenitore di un componente (che nel replace è indicabile con il numero sequenziale di questi oggetti 
      (es.find: ([a-zA-Z]) _([0-9])  ; replace:  \1 , \2, etc)
	. […]=> set di caratteri 
      (es. ([a-zA-Z]) , una lettera dalla ‘a’ alla ‘Z’ ; oppure ([0-9]) un numero 
	. [^…] => set di caratteri negato (l’opposto di ciò che è definito)
	. (.*?)=> qualsiasi cosa (più caratteri) su una riga
	. <singolo elemento>? => indica che l’elemento può non esistere 
      (es. </?span>,prende sia <span> che </span>)
	. ((.*\n)*?.*) => qualsiasi cosa in più linee
	. ((?:.*\r?\n){10}) => salta X(=10) righe
	. (\d)=> uguale a ([0-9])
	. (?!...) : Lookahead negativo. Controlla che all'interno del testo non si verifichi il pattern successivo.
		.. (\b\d+\b)=> cerca un numero con due cifre (es. 30) che non contiene in una parola (es. non è in: ABC35)(\b=> confine di parola) 
Esempio
. find:: <h([0-9])> (.*?) </h([0-9])
